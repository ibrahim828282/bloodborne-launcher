# Bloodborne Launcher

A launcher for Bloodborne on PC: runs **BBport** and **Seamless Co-op** from one place.

⚠️ **The game is not included.** You need your own copy of Bloodborne (CUSA03173, version 1.09).

## Download

**[Latest release](https://github.com/ibrahim828282/bloodborne-launcher/releases/latest)** → `Bloodborne-Launcher.zip`

## Features

- Downloads and installs BBport and Seamless Co-op from their official GitHub pages
- Full graphics settings, set automatically for your PC
- Keyboard, mouse and controller button remapping
- Online sign-in and Seamless account creation
- Save file backups
- 13 languages, automatic updates for the launcher and the mods

## Open source

`Launcher.cs` is the complete source code of `Bloodborne Launcher.exe`. Nothing is hidden: you can read it, and build it yourself with `BUILD (double-click once).cmd` (it uses the C# compiler that comes with Windows). The background, icons, font and translations are in the release zip's exe as resources.

What the launcher connects to:
- GitHub: BBport (Supermedo/bloodborne_pc), BBSC (CLSAMG22/BBSC), shadPS4 patches (shadps4-emu/ps4_cheats) and this repository for updates
- The Hunter's Dream: Discord sign-in for BBport online play
- The Seamless Co-op server you create an account on

It does not send your files or data anywhere else and does not need administrator rights.

Some antivirus programs may warn about it because it is new and not digitally signed. Windows SmartScreen: click **More info → Run anyway**.
